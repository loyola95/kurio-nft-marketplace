# Desvios e ajustes em relação ao Figma

Registro acumulado durante a implementação. Consolidado no ARCHITECTURE.md.

| Tela                                                        | Figma                                                                 | Implementação                                                                                     | Motivo                                                                          |
| ----------------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| Formulários (login, cadastro, perfil, carteiras, pagamento) | Campos só com placeholder, sem label                                  | Label associado ao campo, visualmente oculto; placeholder igual ao Figma                          | README §8: labels e mensagens de erro associadas aos campos                     |
| Ícones                                                      | Set Iconly do arquivo                                                 | SVGs exportados do próprio arquivo via API do Figma                                               | Fidelidade; nenhum ícone substituído                                            |
| Imagens dos NFTs                                            | 4 artes reutilizadas                                                  | As mesmas 4 artes, exportadas em WebP 320/640/960                                                 | Performance; o arquivo só tem 4 imagens, então o catálogo simulado as reutiliza |
| Contraste                                                   | Paleta do arquivo                                                     | Paleta mantida; todas as combinações texto/fundo passam AA (menor razão 5,22:1)                   | Verificado, nenhum ajuste necessário                                            |
| Início: catálogo                                            | Contagens de rede somam 283 (mais que as 239 das categorias)          | Contagens de categoria iguais ao Figma; redes na mesma proporção sobre 239 (100, 66, 73)          | Fixtures precisam de um total coerente para filtros combinados                  |
| Início: paginação                                           | Só números e seta "próxima"                                           | Seta "anterior" aparece a partir da página 2                                                      | Navegação coerente em ambos os sentidos                                         |
| Detalhe: menu                                               | Item ativo "Mercado"                                                  | Mantido; "Início" fica ativo só na tela inicial                                                   | Fidelidade                                                                      |
| Detalhe: descrição                                          | Textos de "Contrato" e "Direitos autorais" trocados                   | Cada rótulo com o texto correspondente                                                            | Correção de conteúdo                                                            |
| Detalhe: galeria                                            | Miniaturas de outros NFTs                                             | Miniaturas são enquadramentos da mesma obra                                                       | A galeria mostra o NFT exibido; o arquivo tem uma arte por NFT                  |
| Login                                                       | Título do modal "Criar conta"                                         | Título "Entrar"                                                                                   | Correção de conteúdo                                                            |
| Início mobile: abas                                         | 4px entre "Todos os NFTs" e "Novos lançamentos", 16px entre as demais | 16px entre todas as abas                                                                          | Espaçamento consistente quando a aba ativa muda                                 |
| Início mobile: banner                                       | Três indicadores na mesma cor                                         | Indicador ativo opaco, demais com 60% de opacidade                                                | Estado do controle visível                                                      |
| Início mobile: botão central da barra                       | Gradiente translúcido sobre o fundo                                   | Mesmo gradiente sobre base sólida da cor do fundo                                                 | O conteúdo rolando por baixo não aparece através do botão                       |
| Filtros                                                     | Sem indicador além da cor no item ativo                               | Sem filtro, idêntico; com filtro ativo, um ✓ no recuo de 12px da lista                            | WCAG 1.4.1: estado não pode depender só da cor                                  |
| Detalhe mobile                                              | Bolinhas da galeria sob a arte (invisíveis)                           | Só a arte principal, sem indicadores                                                              | Fidelidade ao que o frame mostra                                                |
| Detalhe mobile: barra de compra                             | Botão de carrinho sem ação definida                                   | "Comprar NFT" adiciona e abre o carrinho; o ícone adiciona e continua na página                   | Duas ações distintas para os dois botões do frame                               |
| Detalhe: lupa da arte                                       | Ícone de lupa sem tela de destino                                     | Abre a arte ampliada em um modal                                                                  | Estado não desenhado                                                            |
| Detalhe: seletor de quantidade                              | "−" sempre na cor cheia                                               | Cor cheia mantida no limite (só desabilita); seletor inteiro apagado se a edição não está à venda | Fidelidade sem esconder que a edição está indisponível                          |
| Detalhe: "Mais desta coleção"                               | Três indicadores, o do meio ativo                                     | Carrossel de até 3 páginas de 5; começa na primeira                                               | Os indicadores passam a funcionar                                               |
| Tablet (768 a 1023px)                                       | Sem frame                                                             | Detalhe em uma coluna com a arte limitada a 573px; promos empilhadas abaixo de 1280px             | As duas colunas do desktop não cabem nessa faixa                                |
| Dados do Emerald Ape                                        | "Kurio Editions" no texto, "Kurio Apes" na ficha                      | "Kurio Apes" em todos os textos                                                                   | Coerência com a coleção exibida                                                 |
| Login e cadastro (desktop)                                  | Modal sem escurecer a Início; raio 0 no login e 8 no cadastro         | Mesmo modal sem escurecer, raio 8 nos dois                                                        | Um componente para as duas abas                                                 |
| Login e cadastro                                            | "Esqueceu a senha?" e login social sem tela de destino                | Avisam que estão fora da demonstração                                                             | Não simular fluxo que não existe                                                |
| Login e cadastro                                            | Sem estado de sessão expirada                                         | Aviso "Sua sessão expirou" acima do formulário                                                    | README: tratar expiração e voltar ao ponto onde a pessoa estava                 |
| Cadastro mobile                                             | Placeholder "Nome de usuário" centralizado                            | Alinhado à esquerda como os demais campos                                                         | Consistência entre os campos                                                    |
| Senha visível                                               | Só o ícone de ocultar                                                 | Ícone de olho aberto no mesmo traço quando a senha está visível                                   | Estado não desenhado                                                            |
| Lista de interesse                                          | Sem frame                                                             | Dentro do layout "Meu perfil", com a grade de cards e coração para remover                        | Mesmo padrão visual das telas de perfil e catálogo                              |
| Perfil mobile                                               | Sem frame                                                             | Menu "Meu perfil" vira uma faixa horizontal rolável, com "Sair"                                   | A barra lateral de 310px não cabe no celular                                    |
| Perfil e carteiras                                          | Sem rodapé                                                            | Sem rodapé                                                                                        | Fidelidade                                                                      |
| Avisos (toasts) no mobile                                   | Sem estado                                                            | Aparecem a 72px do topo                                                                           | Não cobrem os botões de voltar e favoritar                                      |
| Carrinho mobile                                             | Sem botão de excluir                                                  | Ícone de lixeira no canto superior direito de cada card                                           | README: remover item; o frame não deixa espaço                                  |
| Carrinho desktop                                            | Linha do item mostra só o ID do token                                 | Igual; a edição aparece na linha só quando há duas edições do mesmo NFT                           | Diferenciar itens sem mudar o caso comum                                        |
| Carrinho: desconto                                          | "(-) 00.00"                                                           | "(-) 0.00 ETH"                                                                                    | Mesmo formato dos outros valores                                                |
| Carrinho: taxa de rede                                      | Um valor fixo                                                         | Uma taxa por rede presente no carrinho (cada rede vira um pedido)                                 | Regra de um pedido por rede                                                     |
| Carrinho: avisos                                            | Sem estado                                                            | Banner com preço alterado, estoque ajustado ou esgotado e botão "Entendi"                         | README: refletir mudanças de preço e disponibilidade                            |
| Carrinho: larguras intermediárias                           | Só 1440 e 414                                                         | Cards abaixo de 1024px; tabela com resumo embaixo até 1279px; lado a lado a partir de 1280px      | A tabela de 782px e o resumo de 332px só cabem juntos em 1280px                 |
| Carrinho mobile                                             | Sem "Colecionadores também viram" nem rodapé                          | Igual ao frame                                                                                    | Fidelidade                                                                      |
| Card da grade (desktop)                                     | Estado de hover com carrinho, favoritar e lupa (frame Login)          | Mesmo estado, também visível com o foco do teclado                                                | Acessível por teclado                                                           |
| Início: Diário da Cunhagem                                  | 4 cards de 268px alinhados à esquerda sob título centralizado         | Cards ocupam a largura do conteúdo, alinhados às demais seções                                    | Corrige o desalinhamento entre título e cards                                   |
| Início: NFT em destaque                                     | Título à esquerda e "OFERTA LIMITADA" centralizado                    | Os dois alinhados à esquerda                                                                      | Alinhamento consistente dentro do bloco                                         |
| Perfil e carteiras: Nome ENS                                | Seletor ".eth" ao lado do campo                                       | Sufixo fixo ".eth" na mesma posição, sem seta                                                     | ENS só existe com .eth; um seletor com uma opção confunde                       |
| Perfil e carteiras: obrigatórios                            | Asterisco em quase todos os campos                                    | Validação igual aos asteriscos (só "ENS ou carteira secundária" é opcional)                       | O que a tela marca como obrigatório é o que o formulário exige                  |
| Perfil: Salvar                                              | Um botão para dados e senha                                           | Mesmo botão; a senha só é trocada se os campos de senha forem preenchidos                         | Fidelidade sem obrigar a trocar a senha a cada edição                           |
| Perfil: avatar                                              | "Remover" sempre ativo                                                | Sempre visível; desabilitado quando não há avatar                                                 | Estado não desenhado                                                            |
| Perfil: rascunho                                            | Sem estado                                                            | Se a sessão expirar, as alterações voltam após o login com aviso "Restauramos..."                 | README: manter o contexto ao reautenticar                                       |
| Carteiras: "Adicionar"                                      | Link sempre visível no título                                         | Aparece só quando a carteira ainda não existe                                                     | Com a carteira cadastrada, o formulário já está aberto para edição              |
| Perfil e carteiras mobile                                   | Sem frame                                                             | Uma coluna, mesmos campos e rótulos                                                               | Os dois campos lado a lado não cabem no celular                                 |
